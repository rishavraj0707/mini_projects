# Number Guessing Game

A simple Java console game where the player tries to guess a randomly generated number between **1 and 100**.

## How to Run

1. Compile the program:

   ```bash
   javac NumberGuessingGame.java
   ```
2. Run the program:

   ```bash
   java NumberGuessingGame
   ```

## How to Play

* The program randomly selects a number from **1 to 100**.
* Enter your guess when prompted.
* The game tells you if your guess is **too low** or **too high**.
* Keep guessing until you find the correct number.
* The total number of attempts is displayed when you win.

## Requirements

* Java JDK installed on your system.

## Note

The game uses Java's `Random` class to generate the secret number and `Scanner` to read user input.
